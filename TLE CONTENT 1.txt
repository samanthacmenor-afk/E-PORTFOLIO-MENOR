<h2>💻 LESSON OUTPUT 2</h2>
<img src="LESSON 2.png" alt="Lesson 2 Screenshot">
<p><b>Description:</b> This lesson focused more on the three kinds of CSS: inline, internal, and external. I learned how each one works and when it’s best to use them. Inline CSS is written directly inside an HTML tag, which is useful for small changes. Internal CSS is written inside a &lt;style&gt; tag in the HTML file, and it’s good for single-page designs. External CSS is written in a separate file and linked to the HTML, which is best for larger projects since it keeps the code clean and easier to maintain. This lesson made me understand why developers prefer external CSS when creating big websites.</p>
</div>

<img src="LESSON 4.png" alt="Lesson 4 Screenshot">
<p><b>Description:</b> This lesson taught me how to use classes in CSS to style specific elements on a webpage. I learned that classes are used when you want to apply the same style to multiple elements without repeating code. To use a class, you add a class name in the HTML element and then style it in CSS using a period (.) before the class name. I also learned the difference between classes and IDs — classes can be reused many times, while IDs are meant for one unique element. This made my coding more efficient and helped me create more organized and flexible designs.</p>
